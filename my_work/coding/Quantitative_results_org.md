# Quantitative Results 组织（5.1）

原则：Results 按**构念**排，不要按问卷文件名排。对局行为单独一节，问卷里「位置感 / 风险意向 / 情绪 / 纸上分配」分开。平等条件当对照，不要每个量表都写成「我们也做了 Equal」。

样本（matched pre–post）：不平等 H9 / M9 / L12（n=30）；平等 PRD n=25、DOSPERT n=27、分配场次略有出入。分析：各条件内 Status × Time mixed ANOVA。

## 一句话结果（可写进各小节首句）

### PRD — 不平等出现梯子，平等没有

不平等（n=30）：交互 F(2,27)=20.77, p<.001, ηp²=.61。  
H 3.58→2.42（Δ=−1.16, paired p=.010）；L 3.88→5.35（Δ=+1.47, p<.001）；M 3.02→3.56（Δ=+0.53, ns）。事后 L>M>H。  
平等：Status、Time、交互均 ns。H post 甚至略升（3.53→4.28, ns）。

### PBJW — 低层崩、高层升；平等无分层

不平等：交互 p<.001, ηp²=.60。H 4.74→5.54；M 4.96→4.74；L 5.10→2.44。  
平等：全部 ns。

### DOSPERT — 只有不平等的中层升；低层问卷不升

不平等：交互 p<.001, ηp²=.50。Pre 三组无差。Post：M 4.25 高于 H 2.83 与 L 3.16。Δ：H −0.10 (ns)；M +0.92 (p<.001)；L −0.35 (ns)，L 变化 SD 最大。  
平等：交互 ns；各组几乎平底。

### PANAS — 高层稳；中低阴性情绪升（描述为主）

不平等阳性：H 3.50→3.58；M 4.01→4.43；L 3.80→4.53。Time p=.069，交互 ns。  
阴性：H 2.18→2.18；M 2.18→2.94；L 2.40→3.41。  
不要把 PANAS 写成主结果；用来支撑「高层更稳、中低更被激活」。

### Allocation (REDIST) — 补偿弱势，条件内无 Status×Time

不平等：H/M/L 事后仍倾向给弱势（REDIST 均值约 2.5–3.6），交互 p=.85。  
平等：组间、变化亦均 ns。  
写法：players still compensated the disadvantaged player on the hypothetical task; assigned status did not shift that preference.

### In-game（占位）

报：低层接近/战斗更高；高层回避或延迟下行；Equal 总体事件可能更高且不按层。具体 F 与图插入后，Results 只陈述；「问卷低风险 vs 对局高进攻」的解释放 Discussion。
