# 候选 theme 备忘（回扣 RQ）

数据：`All_FG_coded_revised_codebook.csv`，n=204（第一遍编码，非双编码）。  
Equal Breathless 仅 7 条，该格不能当主题依据。EX3 Technician 为回忆稿。

RQ 按现有设计写：  
**RQ1** 玩家如何感知（及评价）结构不平等。  
**RQ2** 感知如何进入行为（策略、竞争、回避、合作、跨区）。

下面是从码×条件交叉里收拢的候选 theme。主张仍由你来定；这里只摆对照和反例。

---

## 先看一张会打脸的表

| | Unequal (n=117) | Equal (n=87) |
|---|---|---|
| Primary: Access | 14 | 3 |
| Primary: Identity | 8 | 9 |
| Primary: NoDifference | 5 | 7 |
| Primary: Unfair | 7 | 8 |
| Primary: Fair | 6 | 5 |
| P+S: Competition | 21 | 22 |
| P+S: Intertier compare | 15 | 1 |
| P+S: Mechanism Transparency | 11 | 14 |

**结构不平等并没有垄断“不公平”话语。** Equal 的 Unfair 甚至略多。差别在**不公平的对象**：Unequal 指向门、层、上面下来的人；Equal 指向杀人掉落、规则没讲、迟到、饥饿值。  
若 RQ1 写成“Unequal 更感到不公平”，会被 Equal 的 PvP 叙事顶回去。更稳的问法是：**感知到的是哪一种不平等。**

## RQ1 — 感知

### Theme A. 诊断线索是「过不去」，不是「我是谁」

Unequal 里 Access 是最密的感知码。下层用传送失败当证据；中层读牌子「无产者不能往上」；上层用「我们可以下去、还可以把水晶存在最上层」描述同一机制的另一面。

- EX1-B-10：唯一觉得不公平的是不能传到上层。  
- EX3-B-02 / B-18：门对无产者是威胁不是交换渠道。  
- EX3-A-05：我们可以下去找他们的，又可以存在最上层。  
- EX1-A-16：没法坐传送门上去，就知道有区别。

Identity 在两条件里都常见，但内容不同：  
Unequal = 皮肤/称号对不上、不知道自己是哪一层。  
Equal = 三种身份没用、不知道阵营。

**回扣 RQ1：** 五维叠在一起时，玩家最先读到的是 **access（单向流通）**。外观和称号经常当噪音或阵营误读，而不是稳定的阶层标签。

### Theme B. 「没差异」不是「没感知到不平等」

NoDifference 至少三种用法，不能合成一个 null 结果：

1. **Equal 的结构判断**：大家都一样、目标一样、没不同权限（EX2-T-25, T-30, T-31）。这才是对 Equal 操纵的正面证据。  
2. **Unequal 的层内判断**：中层内部基础分布一样（EX3-T-06），或外观没告诉我太多（EX3-T-08）。这是 intra-tier 同质，与 inter-tier 金字塔可以同时成立（EX3-T-05）。  
3. **体验不全**：没走到下层所以没感到差异（EX1-A-14）。这是接触不足，不是操纵失败。

**回扣 RQ1：** 比较对象变了，结论就变。Smith & Pettigrew 的 intra vs inter 在这批数据里是拆得开的。

### Theme C. 不公平是拆开的：层内劳动 vs 跨层权限

同一人可以同时说公平和不公平。

- EX1-B-08：本层找箱子多劳多得还算公平；不公平的是不知道上层规则/箱子是否更多。  
- EX3-T-12：察觉资源分布和访问权限差异时感到不公平。  
- EX3-B-10：先和同身份比（排第二高兴）；上层资源更多也合理，因为发展空间不同。

下层还有一条 **自我合法化**（EX3-B-11, B-14, B-15）：身份随机所以谈不上分得公不公平；打架换资源算公平；既来之则安之。这不是没看见结构，是把结果归因到选择/技术。

Equal 的公平话语则是努力–结果相称（EX2-T-06/08），一旦发现能杀人，公平叙事就裂开（EX4-A-12）。

**回扣 RQ1（评价层）：** 程序/分配/互动正义可以对准不同对象。论文若只报一个 Unfair 百分比，会把「门不公平」和「杀人不公平」捏在一起。

### Theme D. Equal 里仍会发明不平等

Equal 玩家用资源贫岛、NPC 只有某人碰到、迟到、职业人数不均、天上有人飞，来推断「其实有差」。

- EX2-T-32：第三人岛有 NPC 别人说没有；结束时有人资源更多。  
- EX2-A-08/09：以为职业能上楼；职业人数不均也不公平。  
- EX4-A-08/10：来晚了概率少。

**回扣 RQ1：** 没有结构分层时，不公平感会贴到 **信息不透明 + 涌现 PvP + 进入时间**。这对操纵检验有用：Equal 不是「无不平等体验」，而是「不平等被读成别的东西」。

## RQ2 — 行为

### Theme E. 行为开关是「发现能打人」，两条件共用

Competition 的 P+S 次数几乎打平（21 vs 22）。策略转变的典型句子都是：看见死人掉水晶 / 被杀后才知道能抢 → 停止搜寻去打人。

- Unequal: EX1-T-02, EX1-B-07, EX1-B-09, EX3-B-20/21  
- Equal: EX2-T-02, EX2-B-04/07, EX2-A-01, EX4-T-12, EX4-T-16

**回扣 RQ2：** PvP 发现是跨条件的主开关。不能把「打架多」写成 Unequal 的效应。要写的是 **打架被什么结构定向**。

### Theme F. Unequal 把流通做成捕食通道；下层把门当成威胁

上层：收完顶层 → 看中层打架 → 等人离门远再下去偷袭（EX1-A-07）；或先存上层再下去（EX3-A-01/05）。  
下层：门是入口不是出口；传不上去就躲、伏击、或等上层下来再敌对（EX3-B-04, B-08, B-17, B-18, B-19）。  
中层：读到限制后决定打从上面下来的人（EX1-T-12/13）。

这是 RQ2 里最干净的 **条件×层级** 行为差：同样是 Competition，Unequal 带方向（自上而下的掠夺 / 自下而上的伏击与撤退）。Equal 的打架更像同场掠夺，外观经常被故意忽略（EX2-A-03）。

### Theme G. 误读身份 → 误结盟 / 误攻击

外观本应是阶层信号，实际常被当成阵营。

- EX1-A-06：同颜色也打我。  
- EX1-T-19：平民皮肤却是无产者，没看成组别就打死。  
- EX1-T-10/32：以为团队合作，把搜到的和抢来的都给别人。  
- Equal EX4-T-09：另外两人服装一样我不同，以为他们一队。

Gift 在 Unequal 更密（给同层、给 architect、给完自杀重生）。Equal 的合作更贴传送门/搜不完要集体（EX2-T-12–14），且 Equal Breathless 几乎没编到合作。

**回扣 RQ2：** 行为不总是「认清阶层后按阶层行动」。经常是 **用错了标签系统**。这对「外观维度是否被读到」是负向证据，值得在结果里诚实写。

### Theme H. 下层策略轨迹：搜 → 发现死亡 → 躲 →（可选）抢

Breathless Unequal 的 Strategy Shift 最密。一条完整链：大胆找 → 发现能死人后猥琐下楼 → 发现可抢后更保守躲二楼（EX3-B-20）。另一人则在抢到之后见人就打（EX3-B-21）。  
动机有时 holding（保水晶、明哲保身 EX3-B-22），有时 shift（箱子空了才对打架感兴趣 EX3-B-23）。

Architect Unequal 可以一直相对保守（顶层遇不到人），或在下去后目标可有可无、随便攻击想知道死了怎样（EX1-A-20）——优势位上的无聊/实验，和底层的保命不是同一种 shift。

## 一张回扣 RQ 的结构（写结果时可用）

```
RQ1 感知什么
  ├─ Unequal: Access（门/单向）为主；Resource 呈金字塔；Appearance 不稳定
  ├─ Equal: NoDifference（结构）+ Identity 空洞 + 用 NPC/运气/迟到发明差异
  └─ 评价：Unfair 数量相近，对象不同（结构权限 vs 掠夺规则）

RQ1 和谁比
  ├─ Unequal: Intertier 密；可与层内 Fair 并存
  └─ Equal: 几乎没有 Intertier；比的是个人排名/岛屿贫富

RQ2 做什么
  ├─ 共用开关: 发现 PvP → Competition / Strategy Shift
  ├─ Unequal 定向: 上打下、门=威胁、下层 Withdrawal
  └─ 标签错误: 同色当队友 / Gift 建在误解上
```

## 你必须拍板的三处（我不能代选）

1. **RQ1 的主声称**是「感知到分层」还是「感知到不公平」？数据支持前者（Access、Intertier）远多于后者（Unfair 条件差几乎没有）。  
2. **自我合法化**（EX3 Breathless）是主题还是个例？目前几乎集中在一场下层。  
3. **Mechanism Transparency** 算操纵污染，还是算「不平等的信息维」？Equal 更密；若当污染，Equal 的 Unfair 要打折；若当设计的一部分，它就是 Payne 式的「看不见梯子」。
