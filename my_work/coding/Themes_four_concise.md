# Four themes

总逻辑：不平等首先通过 **access** 被感知（T1）；感知到的结构位置进而分化出不同的风险取向（T2）；可识别的层级位置强化 identity，并促使玩家寻求合作（T3）；两种条件都会出现 risk-taking，但其行为目标不同（T4）。

---

## Theme 1. Access 是感知不平等最直接的线索

在五个不平等维度中，玩家最先、也最稳定用来判断「我与他人不同」的是 **access**：传送门是否可用、能否上行、流通是否单向。外观与称号常被误读为阵营；战斗数值在两条件中相同，因此感知到的社会位置并非来自能力差异，而来自通行限制。

下层以通行失败为证据：「唯一觉得不公平的是不能传送到上层」「站上去没反应，才知道这层不能往上爬」。上层用同一机制描述特权：「我们可以下去找他们的水晶，又可以把水晶存在最上层」。中层通过标识读取规则：「无产者不能往上走」。

平等条件没有这一限制，身份标签缺乏结构含义：「大家都一样」「对自己的层级没有什么概念」「能力玩法感觉都一样」。

对应量表：个人相对剥夺（PRD）仅在不平等条件中按层级分化；平等条件虽有 H/M/L 标签，PRD 并不分层。

---

## Theme 2. 不平等条件下，风险取向随层级分化

感知到结构位置之后，风险行为并非「地位越低越冒险」。DOSPERT：中层显著上升；Architect 略降；Breathless 均值略降，个体差异更大。

**中层（Technician）。** 同时面对来自上层的下行攻击，自身又无法撤退至顶层。因此更可能中断搜寻、对下行玩家反击：「看到限制后，我决定攻击从上面下来的任何人」「停止搜寻，转而攻击其他玩家」。下层亦指出：「中间两面受敌最难受」。这与中层 risk-taking 上升一致。

**上层（Architect）。** 资源与上行逃路已经具备，主导策略是 risk avoidance：收完顶层资源、遇人回避、将物品存储于上层后再决定是否下行。「先把顶层大部分水晶收完，看到人就躲」「下去可能全丢」。下行会暴露已有资源；留在顶层可以维持既有优势。

**下层（Breathless）。** PRD 最高，行为却不一致：有人「躲在二楼连脸都不敢露」；有人被杀后「只想复仇」「见人就打」。群体均值未如中层那样整体上升，回避与反击并存。

---

## Theme 3. 不平等条件中 identity 更强，玩家更寻求合作；平等条件中则不然

Access 与外观使层级可识别之后，玩家开始使用「我们 / 我方 / 同阶层」，并寻求合作与给予。平等条件中称号不对应特权，攻击可以忽略外观；若出现合作，多针对共同进入传送门或搜索效率，而非层级认同。

不平等：「外观和不同层会不自然地把人分成阵营、合纵连横」「只希望同阶层排名都靠前」「我方击败蓝方会受鼓舞」。给予发生在同层或同身份之间（中层误以为组队而给予；Architect 给予其他 architect；下层亦有获赠）。

平等：「杀人时不管对方穿什么衣服，只要拿水晶」「我都不知道什么阵营不阵营」。

合作与给予在不平等条件中更明确，但不限于底层；上层同样向同身份玩家给予。Identity 强化的前提是层级可识别，而非劣势本身。

---

## Theme 4. 两种条件下 risk-taking 的行为目标不同

两条件中攻击与掠夺都常见。差异在于 **行为指向什么**。

**不平等：指向结构位置。** 攻击具有层级方向——上层下行掠夺，中层攻击下行者，下层在传送门伏击或报复上层。「本地资源收完后上层来掠夺，才对上面两层充满敌意」。Risk-taking 用于维持或改变自身在结构中的位置。

**平等：指向被发现的掠夺规则。** 不存在跨层通行特权，转折点是发现击杀可掉落资源：「无意中发现打死对方能拿水晶，后来就打人」「大家知道可以杀人后，击杀频率明显上升」。玩家评价为不公平的，是劳动所得被掠夺、规则未经说明，而非通行被拒。

因此平等条件同样出现 PvP，DOSPERT 却不按层级分化：缺乏与结构位置相关的风险动机，风险行为由涌现的掠夺机制驱动。

---

## 与量性结果的对应

T1 → PRD 仅在不平等条件中按层分化。T2 → DOSPERT 仅中层上升，Architect 倾向回避，Breathless 回避与反击并存。T3 → 不平等条件中层级身份可识别，合作与给予随之出现。T4 → 平等条件亦有攻击，但目标是规则被发现后的资源掠夺，故量表不按层分化。
