# Mixed-methods theme map（qual 辅助 quant）

量性来源：Exp1–4 notebook。不平等 n=30（H9 / M9 / L12）；平等 PRD n=25、DOSPERT n=27。  
质性来源：`All_FG_coded_revised_codebook.csv`（第一遍编码）。  
用法：量性报 **发生了什么**；质性报 **玩家如何读到位置、如何把位置变成赌注和行为**。不要用质性去“证明 p 值”。

两条链先对齐量表，再对齐 theme。不要把 PRD 和 DOSPERT 合成一个“不平等效应”。

| 链 | 量表（不平等条件） | 质性该解释的缺口 |
|---|---|---|
| Chain 1：五因素 → 感知不平等 → 感知社会位置 → 主观赌注 → 风险/回避 | **PRD** 变成阶梯：H 3.58→2.42；M 3.02→3.56；L 3.88→5.35。交互显著。平等条件 **没有** 这把梯子（H post 甚至最高）。**DOSPERT** 不是梯子：只有 **M +0.92** 显著；H −0.10、L −0.35，H 与 L 事后无差。平等 DOSPERT 几乎平底。 | 为什么位置感是 L>M>H，风险却是中间凸起？ |
| Chain 2：共享劣势 → 内群认同 → 给予/再分配 | **PBJW**：L 5.10→2.44 崩掉；H 4.74→5.54 上升。平等三组都略降、组间无差。 | 认同和 Gift 是不是下层专属？再分配流向少数还是流向能上楼的人？ |

**幸福者避让 / preserving advantage** 对的是 H 的 PRD↓ + DOSPERT 不升。  
**中间冒险** 对的是 M 的 DOSPERT↑。  
**下层相对剥夺** 对的是 L 的 PRD↑ + PBJW↓，不是 DOSPERT 均值上升。

## Theme 1 — 可读的不平等是位置，不是数值（辅助 PRD 梯子）

**量性要解释的：** 攻击力/体属性两条件相同，但只有不平等条件出现 PRD 的 Status × Time 交互；平等条件标签仍是 H/M/L，PRD 却不分层。

**质性主张：** 玩家用 **Access（过不去 / 单向下去）** 当比较点。没有比较点就读不到真实层级（Payne：gap 要有 ladder）。外观经常读错；Identity 在平等里是空标签。

证据：EX1-B-10、EX1-A-16、EX3-B-18、EX3-A-05；平等 EX2-T-25/31「大家都一样」。  
Intertier 比较 P+S：Unequal 15 vs Equal 1。

**五因素怎么写才贴量表：** 不要写“五个因素同等贡献”。写成：设计叠了五维，**被读到并进入 PRD 的主要是 access + 可见的资源/空间差**；appearance 不稳定；combat 数值被设计成相同，所以阶梯只能来自结构位置。

**Broken Ladder 对照：** 真实层级在不平等里被门点亮；平等里没有门，玩家仍会用 NPC/迟到/杀人发明差异（Theme 里的“假梯子”），那是 Equal 的 Unfair，对不上 PRD 阶梯。

## Theme 2 — 主观赌注按层分叉（辅助 DOSPERT 中间凸起 + L 的方差）

量性：pre 三组 DOSPERT 无差；post 只有 M 显著高于 H、L。L 的 **变化 SD=0.77**（H=0.36），均值下降掩盖两极。

质性按层填机制（不要写成“下层更冒险”）：

### 2a Architect：保有量 → 避险（幸福者避让）

稳定资源、能存上层、能选择何时下去。策略是等、躲、再下去偷袭，而不是开局对拼。  
EX1-A-04、EX1-A-07、EX3-A-01/05。DOSPERT 微降、PRD 大降：位置变好，赌注变成“别把优势打没”。

### 2b Technician：两面受敌 → 风险上升（贴 DOSPERT 的主 theme）

中层既会被上层下来打，又比下层多一点流通。FG：读到牌子后专打上面下来的人；策略从搜箱切到打人/躲。  
EX1-T-12/13、EX1-T-02、EX3-B-25（下层也在猜“中间两面受敌最难受”）。  
Shift 在 Unequal Tech 不少（5），Competition 7。这是 **夹层赌注**：不打会被收割，打才是保位置。

### 2c Breathless：均值避险 + 行为两极（贴 L 的 DOSPERT SD，而不是均值）

同一层里：躲二楼、门当威胁（Withdrawal 在 Unequal Breathless 最密）**和** 见人就打、伏击传送门并存。  
EX3-B-08/17/20 vs EX3-B-21/19。均值 −0.35 像风险厌恶；质性说明这是 **保水晶的回避** 与 **偶发掠夺** 的混合，不是统一的 risk-seeking。

## Theme 3 — 内群是被门和外观催出来的，Gift 不是下层专利（辅助 Chain 2，但要收口）

**能辅助的：** 不平等里出现“我方/同身份/同色”；平等里少有阶层意识，Gift 少。Equal 的合作主要是 Technician 的传送门/搜不完要集体（物流，不是内群）。这能解释为什么平等里“按身份再分配”弱。

**不能直接写的：** “Breathless 因为劣势所以互助最多”。当前编码：Gift 在 Unequal 是 Arch 2 / Tech 3 / Breath 1。上层也把水晶给其他 Architect（EX3-A-02/03）。下层更强的是 **认同话语**（合纵连横、我方击败蓝方、同阶层都靠前），不是赠与次数。

**再分配方向要拆开，否则和“流向少数”打架：**

1. **结构流通：** 上层可下去抢、可存顶层 → 水晶向能上楼的人集中（EX3-A-04/05）。这是 **向上/向优势位**，不是流向少数底层。  
2. **内群赠与：** 同层误当队友、Architect 内部给。  
3. **问卷 allocation：** 另表；不要和局内掉落混写成同一个 redistribution。

Chain 2 建议改成：共享可见劣势 → **认同与敌对定向** → 有时 Gift；资源总流向仍被 access 决定。

## Theme 4 — 公平世界信念的破裂（辅助 PBJW）

L 的 PBJW 崩塌，H 上升。质性：下层骂门不公平、被资源更多的人打死；也有人合法化（既来之则安之、打架换资源算公平）。H 有人说不平衡里有掰回公平的机制（EX1-A-17）。  
平等 PBJW 三组一起略降，对应“杀人规则没讲清”的程序不公，不是阶层不公。

## 建议的 Results 叙事顺序（qual 只辅助，不另起炉灶）

1. 操纵：PRD 阶梯只在不平等出现。Qual：门是比较点。  
2. 机制：位置进入赌注。DOSPERT 中间凸起。Qual：中层两面受敌；上层保有；下层两极。  
3. 社会行为：认同与 Gift 是条件差，但流向要诚实。  
4. Equal：无位置感、无保优势、Unfair 指向规则/PvP——解释为什么量表不分层、局内却仍打架。
