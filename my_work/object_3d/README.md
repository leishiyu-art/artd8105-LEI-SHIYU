# triangles_trace_shell — B · 扭矩螺旋三角管

你选了 **B**，并且要求：叠棱柱既不是一块、也不可打、也不够好看；用**扭矩螺旋曲线**把 triangle 连成一条。截面仍是自由三点三角，不是圆管。

几何节点里不再 Repeat 8 颗棱柱。痕迹是一条螺旋，三角剖面沿曲线扫过，扭矩绕切向拧，过一半（Reverse 开）拧向平滑反号。

## 现在用的参数

Count 8（沿螺旋取样，不是 8 颗分立棱柱）· Overlap 0.70（加在扭矩上，不再加圈数）· Size Min / Max **6 / 12 mm** · Wall **2.5 mm** · Correlation 0.35 · Max turn 35° · Reverse on · Beat N 4 · Beat scale 1.45 · Seed 1 · Fade affects size off · **Helix Turns 1.0** · Helix Radius 16 mm · Torque Deg 240。

**Helix Turns = 1.0 不是造型偏好。** 圈数 × 截面外伸如果大于螺距，相邻圈会咬穿。Size Max 12 mm 时，1.0 圈、高 28 mm 是目前这组尺寸下刚好错开的下限。你要更密的螺旋，先把 Size Max 降下去再加圈。Helix Radius、Torque Deg 仍由你转。

## 这条打印线过不过

1. **一块**：是。一条曲线扫成一根闭合三角管，没有布尔。  
2. **最薄处 1.20 mm**：刚踩在 1.2 线上。尖角仍尖；切片机会在棱上变细，若要更稳再抬 Size Min / Wall，不要整体放大来假装。  
3. **Z 最低 3.38 mm**：不穿床。在 80×80×40 盒内。

视口：`helix_viewport.png`。

### 下一步你转（我不动手）

- **Helix Turns** — 更盘旋，同时要更瘦的截面。  
- **Helix Radius** — 更开 / 更收。  
- **Torque Deg** — 拧得更狠或更平。
